# VITEXOL APP

Aplicación móvil para la gestión de productos, reparaciones, citas y atención al cliente de la empresa VITEXOL.

## Descripción del sistema

VITEXOL APP es una aplicación móvil desarrollada para facilitar la comunicación entre la empresa VITEXOL y sus clientes.

La aplicación permite acceder a los principales servicios tecnológicos de la empresa desde un dispositivo Android. Su primera versión incluye pantallas de bienvenida, inicio de sesión, registro de usuarios y un menú principal con acceso a los módulos de productos, reparaciones, citas y perfil.

Actualmente, el proyecto se encuentra en una etapa de prototipo funcional. Las pantallas y la navegación principal están implementadas, mientras que la autenticación y el almacenamiento de información mediante Firebase se incorporarán en etapas posteriores.

## Objetivo general

Desarrollar una aplicación móvil que permita optimizar la gestión de productos, reparaciones, citas y atención al cliente de la empresa VITEXOL, ofreciendo una experiencia digital rápida, organizada y accesible.

## Funcionalidades implementadas

- Pantalla de bienvenida.

Para ejecutar el proyecto se necesita:

- Flutter SDK instalado.

- Git.
- Conexión a Internet.

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/yerniso-n/vitexol_app.git
```

Entrar a la carpeta del proyecto:

```bash
cd vitexol_app
```

Descargar las dependencias:

```bash
flutter pub get
```

## Ejecución

Conectar un dispositivo Android con la depuración USB activada o iniciar un emulador.

Después ejecutar:

```bash
flutter run
```
